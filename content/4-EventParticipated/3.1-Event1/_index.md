## Event 1: AWS First Cloud AI Journey Kickoff

**Event Name:** AWS First Cloud AI Journey — Workforce Bootcamp Kickoff  
**Date:** June 6, 2026  
**Location:** Ho Chi Minh City (In-person / Online hybrid)  
**Organizer:** Amazon Web Services Viet Nam Company Limited  
**Role:** Participant (intern)

---

### Event Overview

The kickoff event marked the official start of the **AWS First Cloud AI Journey** bootcamp — a 12-week intensive program designed for university students to gain hands-on experience with AWS cloud and AI/ML services.

### Agenda

| Time | Activity |
|------|---------|
| 09:00 – 09:30 | Opening ceremony & welcome speech |
| 09:30 – 10:30 | Introduction to AWS Cloud fundamentals |
| 10:30 – 11:30 | Overview of the 12-week program structure |
| 11:30 – 12:00 | Team formation & project assignment |
| 14:00 – 16:00 | AWS account setup workshop |
| 16:00 – 17:00 | Networking with AWS staff and alumni |

### Key Takeaways

1. **Program Structure:** 12 weeks covering Cloud Fundamentals → ML/AI → Deployment → Portfolio
2. **Project:** Teams of 3 would build an end-to-end ML project using AWS services
3. **Assessment:** Final grade based on a workshop website, worklog, proposal, blogs, and events
4. **Industry Connections:** Opportunity to network with AWS solution architects

### Personal Notes

This event set the tone for the entire internship. Meeting the team (Huynh Kim Quy, Van Thai Quan, Nguyen Ngoc Sang) and aligning on the Rossmann Sales Forecasting project gave us a clear direction from week 1.

The most valuable insight from the kickoff: *"Don't just run tutorials — build something real, document your failures, and the learning will be 10x more valuable."*
