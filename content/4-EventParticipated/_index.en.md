# Technical Seminars & Events Participated

During the **AWS First Cloud AI Journey (FCAJ)** internship program, I had the opportunity to attend specialized seminars and technical workshops both in-person at the AWS Vietnam office and online. AWS Solutions Architects and industry experts shared invaluable insights regarding production cloud engineering and artificial intelligence trends.

Here are the key events I attended during the internship:

---

## 1. Event 1: AWS First Cloud AI Journey Kickoff

- **Event Name:** AWS First Cloud AI Journey — Workforce Bootcamp Kickoff  
- **Date:** 06/06/2026  
- **Location:** Ho Chi Minh City (Hybrid In-Person at AWS Office / Online)  
- **Organizer:** Amazon Web Services Viet Nam Company Limited  
- **Role:** Participating Intern  

### Event Overview & Agenda
The orientation event marked the official launch of the **AWS First Cloud AI Journey** bootcamp—an intensive training program designed for university students to gain hands-on experience with AWS Cloud and AI/ML services.

| Time Schedule | Primary Agenda Item |
|---------------|---------------------|
| 09:00 – 09:30 | Opening Ceremony & Welcome Speech |
| 09:30 – 10:30 | Introduction to AWS Cloud Infrastructure |
| 10:30 – 11:30 | Program Structure & Internship Expectations |
| 11:30 – 12:00 | Team Formation & Project Proposal Assignment |
| 14:00 – 16:00 | AWS Account Setup & Environment Workshop |
| 16:00 – 17:00 | Q&A Networking with AWS Solutions Architects |

### Key Takeaways & Contributions
- Understood the project evaluation framework and technical deliverables for production cloud deployment.
- Formed a 3-person team (Huynh Kim Quy, Van Thai Quan, Nguyen Ngoc Sang) and finalized our project topic: **Rossmann Retail Sales Forecasting with Amazon SageMaker**.

## 2. Event 2: AWS Study Group Weekly Technical Session

- **Event Name:** AWS Study Group — Weekly Technical Workshop  
- **Date:** 15/07/2026  
- **Location:** Online (Zoom / Google Meet)  
- **Organizer:** AWS Study Group Vietnam  
- **Role:** Participant & Technical Q&A Contributor  

### Event Overview & Agenda
The AWS Study Group organizes weekly online technical sessions where practitioners and students share hands-on cloud engineering experience. This session focused on **SageMaker Endpoints and Serverless Inference Architecture**—directly supporting our Week 6 deployment tasks.

| Presentation Topic | Duration |
|--------------------|----------|
| SageMaker Real-Time & Serverless Endpoint Patterns | 30 mins |
| AWS Lambda Integration with SageMaker Runtime | 20 mins |
| Implementing IAM Least Privilege Security for ML Workloads | 20 mins |
| Deep-Dive Technical Discussion & Q&A | 30 mins |

### Project Application & Personal Takeaways
- **SDK Issue Resolution:** Learned region-specific container image URI resolution using `sagemaker.image_uris.retrieve()`, which permanently fixed our Week 6 deployment `ValidationException` error.
- **Knowledge Sharing:** Contributed to the Q&A discussion by sharing practical techniques for resolving XGBoost library version mismatches and managing AWS Service Quotas.
